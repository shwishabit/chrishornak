SCANDISK · SALVAGE

Jam 2 · Team B (real time). The last working machine. A virus is eating the drive. You save what you can.

▶ Play it

The six rules

  1. Real time. Red takes a cell every few seconds and never stops. The more files it eats, the faster it spreads.
  2. One order. Move the cursor with the D-pad. X sends your picked worker there. Z picks another worker.
  3. Carry. A worker who steps on a file copies it (a few seconds, standing still), then carries it to the PORT by himself. That file is SAVED.
  4. Wall. Red cannot enter a worker's cell. It bites him instead and loses that tick. Three bites and he is gone for good.
  5. Loss. Red on a file eats it. A carried file dies with its worker.
  6. The end. Files surface one at a time. When the last of the eight is saved or eaten, the board ends. Save 4 to keep the sector.

The first ten seconds

The gym board opens with one worker, one file and one slow patch of rot in the far corner. The sign under the board says: WALK ONTO THE FILE. HE COPIES IT, THEN CARRIES IT TO P BY HIMSELF. You move the cursor onto the file and press X. That is the whole game learned. Then the real drive starts.

The one idea

A worker is either a carrier or a wall, never both. You only have four of them, so every rescue opens a hole and every hole you plug is a file you are not saving. That single trade-off is the whole game.

Sound

Sine tones only, none above 262 Hz, all quiet. Red growing is 82 Hz; a bite 98; a save 147 then 196; a file eaten 73. No flashing — a fresh red cell blooms over half a second.
