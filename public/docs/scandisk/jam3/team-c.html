CROSS-LINKED

Why not just Othello? Every file you write also bites the chips beside it, and every chip you own has one square that can bite it back.

  1. Write a file on an empty sector. Trapped virus lines flip, like Othello.
  2. Pick its type: ▲BAT beats ■TXT beats ●WAV beats ▲BAT.
  3. Cross-link: your new file also turns each virus chip it touches (up, down, left, right) whose type it beats.
  4. A move must turn at least one chip. Types never change, only colour.
  5. Stuck? Quiet write: place any type next to your own chips, turning nothing.
  6. Disk full = scan over, most sectors wins. Lose every chip and you lose.
