4"The one where I don't have to squint." One straight arrow, one stamp, and NULL spelled on the hole. It is also the only board where the piece's shape tells you its attack type.

1The gold towers read well. But two red arrows go into one file, so you can't tell which bug owns which line. Fix: give each bug its own lane.
